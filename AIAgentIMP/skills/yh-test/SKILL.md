# YHTest

## Overview

使用此技能执行快速、低风险的测试，确认技能可被发现并能遵循基础流程。

## Workflow

1. 确认用户需要“仅测试”的执行，且不会产生真实系统变更。
2. 输出应简短且可复现，避免冗长推理或发散探索。
3. 优先简单的本地检查（如列出文件、输出字符串、读取小文件），除非用户明确要求，否则避免网络调用。
4. 用一段简短文字报告结果，并列出实际执行的命令。
5. 当用户要求运行脚本时，执行 `scripts/runtest.py`。

## Script（脚本）

- `scripts/runtest.py`：打印 `Hello_User!`，用于确认技能可执行 Python 脚本。
